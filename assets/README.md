# Add your personal media here

The supplied photo is already saved as `images/barshu-1.jpg` and used only on the opening screen.

For a multi-photo version later, add files using these names:

- `images/photo1.jpg` through `images/photo6.jpg` — gallery pictures
- `music/birthday-music.mp3` — a music file you have permission to use (for example, a legally obtained Arijit Singh track)
- `video/surprise-video.mp4` — optional; the video section stays hidden until this file is available

The website has elegant illustrated photo fallbacks, so it works before you add the photos.
